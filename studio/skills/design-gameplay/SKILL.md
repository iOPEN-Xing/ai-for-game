# 从玩家动作写起

从创意中找出玩家反复做的决定。候选方向要在决策、操作节奏或空间关系上有实际差异。用一句可试玩的描述串起输入、世界状态的变化、即时反馈和这一局的目标。

第一关只引入完成核心循环所需的信息。明确玩家看到的第一件事、第一次有效触摸的结果、犯错后的反馈与重试成本。GDD 中的动词必须能映射到画布输入或状态更新。把氛围词落实成目标标志、前景轮廓、背景对比或声音事件。

为触屏画出命中范围。邻近目标需要可辨的间距。玩家即使静音，也应能区分命中、失误和通关。重要状态同时用形状、运动或文字表达。对移动目标检查速度与命中半径的组合，避免让手指遮住下一步决策。

调整旧版本时，引用已选方向和评审意见。说明本轮改变哪一项行为、保留哪项熟悉操作，以及试玩者怎样观察差异。把“觉得更好玩”细化为具体动作或玩家反馈，作为候选假设交给运营验证。

参考 [Game Accessibility Guidelines](https://gameaccessibilityguidelines.com/basic/)。
