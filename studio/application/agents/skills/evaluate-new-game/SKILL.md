# 新游戏立项

先锁定一个北极星指标。分析师记录受众、样本量、同类可比口径、必须满足与避免的条件。评审核对 dead_ends 中的所有记录及证据边界。两份前置产物齐备后，设计师提交两到三个核心循环不同的候选，说明谁会玩、具体的输入与反馈、与现有项目的差异和引用来源。

分析师逐项挑战可以改变推荐结果的假设。每个责任人独立答复，无法提供证据时保留异议。主持人选择一个候选，记录其余原名和淘汰理由。终审复核已有作品重合、流量偏差和北极星口径。

上线预期是新游戏自身的绝对指标区间。写出观察时间、人数、分母及失效条件，等待人工立项。证据不足时可以暂缓立项。
