# ADR-004　阿里云轻量服务器上的单制作室

本次交付采用用户确认的“内部团队制作，公众试玩”。运营团队维护同一个制作室，公众从链接进入已发布作品。项目保留 AgentScope 生产与运营两条工作流，以及人工审批、实验和证据可追溯要求。

Caddy 独占公网 HTTP 与 HTTPS。制作台端口仅绑定服务器回环地址，团队使用各自获准的 SSH 连接和制作台口令。制作台权限在团队内共享，编辑偏好通过独立浏览器凭据保存。SSH 访问记录和制作台事件可分别追查，业务记录的编辑身份精度为浏览器档案。人员离开团队时应收回其 SSH 访问并轮换团队口令。

匿名玩家可游玩、提交对局、提示和评分。自由文本留在工作室数据库，进入专家材料的是聚合评分。公开流量进入分析的路径为正式数据、冻结观察窗和运营提案。样片不占正式分母。生产包和数据库沿用原有契约，服务器部署、检查和备份统一使用 Compose。

SRS v2.2 和 ADR-003 继续描述向外部团队开放制作、注册工单与商业化 API 的产品目标。实施那些产品功能时，应采用其中的成员权限、数据隔离、审批和预算设计。当前交付的准入边界与运维验收以本决定和运行手册为准。[运行架构](../ARCHITECTURE.md) · [运行手册](../RUNBOOK.md)
